NetPulse 1.0 — компактный монитор сети для Windows 11

ЗАПУСК
Откройте NetPulse.exe. Установка и права администратора не нужны.
Рядом с EXE оставьте NetPulse.exe.config. Приложение использует .NET Framework 4.8.
При повторном запуске показывается уже открытый виджет.

УПРАВЛЕНИЕ
• Перетаскивайте окно мышью за фон или заголовок.
• Кнопка «−» или двойной щелчок по фону: компактный режим.
• Кнопка «···» или правая кнопка мыши: настройки и выход.
• Esc: скрыть окно в трей. Двойной щелчок по значку в трее: вернуть.
• Выход: меню «···» → «Выход», меню значка в трее или Alt+F4.
• Поверх всех окон, единицы и сетевой адаптер выбираются в меню.

КАК ИЗМЕРЯЕТСЯ СКОРОСТЬ
Обновление — раз в секунду. Голубой — загрузка, фиолетовый — отдача.
График показывает до 60 последних измерений на общей автоматической шкале.
Байтовые единицы десятичные: 1 КБ = 1000 байт; 1 МБ = 1 000 000 байт.
Можно переключиться на биты: 1 байт = 8 бит.

Автоматический режим суммирует активные физические адаптеры. VPN и другие
виртуальные адаптеры отдельно не прибавляются. Если физических адаптеров нет,
выбирается один активный виртуальный адаптер с наибольшей скоростью канала.
При необходимости выберите конкретный VPN или адаптер в меню.
Учитываются IPv4, IPv6 и локальная сеть. Это текущий трафик всего компьютера,
а не тест максимальной скорости интернет-соединения и не статистика отдельных программ.
Зелёная точка означает активный адаптер; доступность интернета не проверяется.
После смены адаптера, сна и подключения счётчики начинают с новой точки отсчёта.
История существует только в памяти. Приложение не перехватывает пакеты,
не отправляет телеметрию и не создаёт собственные сетевые запросы.

НАСТРОЙКИ
Положение окна, режим, единицы и адаптер сохраняются в NetPulse.settings.xml
рядом с EXE. Используйте папку с доступом для записи. Автозапуск не включается.
Для автозапуска можно самостоятельно добавить ярлык EXE в папку автозагрузки Windows.

СБОРКА ИЗ ИСХОДНИКОВ
В PowerShell из папки проекта: .\build.ps1 -Test
Компилятор .NET Framework берётся из Windows. NuGet и загрузки не нужны.
Результат: dist\NetPulse.exe. Исходники: src\.
Тесты проверяют расчёт скоростей, сбросы, переподключения, выбор адаптеров,
формат единиц, сохранение настроек и совместимость структуры с Win32.
